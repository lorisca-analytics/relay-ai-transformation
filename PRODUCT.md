# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS and JavaScript, no build step, hosted on GitHub Pages. Tests run with Node's built-in test runner in CI.

## Users

The main viewer is a hiring manager or recruiter who clicks through from Lori's portfolio and gives it about two minutes. They want to see how she thinks: how a warning reaches the right person, and where AI is and isn't allowed to act. The in-world users the tool imitates (operations lead, support agents, community and finance leads) shape the content, not the layout priority.

## Product Purpose

A working demo of the reflex the team recommended for Relay, a fictional $600M activewear brand: every warning sign gets one named owner and a clock, AI drafts but people decide, and customer-facing AI is checked before it sends. Success: in two minutes a viewer can replay December, see the 11-day delay shrink to hours, and try the message check.

## Positioning

It's a rebuild of a team prototype, done honestly: numbers come from replayed made-up data, the message check is labelled as rules (not AI), and each tab names the decision it drives and who owns it.

## Operating Context

Opened from the Work hub card or the repo README, on desktop or phone, by someone who hasn't read the case. All data is synthetic and labelled as such.

## Capabilities and Constraints

- Four tabs: stock alarm, sizing check, message check, customer value.
- No AI calls, no API keys, no vendor or tool names, and no real people's names. People in the case appear by role.
- No real case data: the case workbooks stay private. Figures in the README trace to the case.
- The original design is the team's. The README credits it.

## Brand Commitments

Wears Lori's portfolio brand, taken from lori-sca.github.io: Archivo headings, system body font, ink #1e2d42, steel #4a6a8f, cobalt accent #3f5fd0, mist surfaces, 14px radius, light and dark themes. Voice: plain, first person in the README, no hype.

## Evidence on Hand

The team's original prototype and dashboard, the case text, and the team's analysis and KPI documents, all kept private. The repo holds only made-up data.

## Product Principles

1. Every number has a source or says it's made up.
2. Every alert has one owner and a clock.
3. AI drafts, people decide, and the page says which is which.
4. Show the decision a metric drives, not just the metric.

## Accessibility & Inclusion

WCAG AA contrast in both themes, full keyboard use, status never shown by colour alone, reduced motion respected.
